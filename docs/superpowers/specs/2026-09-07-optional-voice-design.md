# 텍스트 전용 private pilot 설정

사용자는 Codex 구독 인증을 사용해 Slack·Telegram 텍스트 명령을 실행하려고 하며, 음성 전사 API 키를 발급하지 않는다.

## 결정

새 설치의 OpenAI 키 빈 입력은 `voiceMode: disabled`를 저장한다. 키를 입력하면 `openai`를 저장한다. 기존 설정에서 모드가 없으면 기존의 음성 필수 동작을 유지한다. 기존 disabled 설정은 빈 입력으로 유지하고, 키를 새로 입력하면 openai로 전환한다. 기존 Keychain 계정은 삭제하지 않는다.

`doctor`는 명시적으로 disabled인 음성만 `skip`과 비활성 설명으로 보고한다. 필수 검사에서 skip이 나오면 실패로 처리한다. 음성을 켠 설정에서 키가 없으면 계속 실패한다. 설정 파일에는 비밀 값을 저장하지 않는다.

계정 유무만으로 모든 기존 설정을 텍스트 전용으로 바꾸면 손상된 음성 설정을 숨길 수 있으므로 명시적 모드를 선택했다. 가짜 API 키로 검사를 통과시키는 방식은 사용하지 않는다.

## 검증과 적용

실제 CLI의 빈 음성 입력, Keychain 및 설정 저장, doctor JSON, 비밀 비출력과 기존 설정 회귀를 검증한다. 개발 작업은 기존 dev worktree에서 수행하며 보호 대상 roadmap은 status에 존재하는 것만 확인한다. 설치본 적용은 변경한 파일만 명시적으로 복사하고 빌드한다.

현재 입력 대기 중인 구버전 setup은 새 코드를 반영하지 못하므로 재실행이 필요하다. 메모리에서 자격증명을 추출하지 않는다. 외부 gateway 연결 모듈 구성과 실제 메시지 시험은 별도 완료 조건이며 doctor 통과만으로 pilotReady를 선언하지 않는다.
